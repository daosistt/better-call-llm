# Math Copilot

Текущий шаг: текстовая задача → OpenAI API → потоковое решение с LaTeX.
В интерфейсе можно загрузить короткий аудиофайл и распознать его локально.
Захват звонка пока не подключён.

Зависимости проекта добавляем через `uv add`. Для общего окружения используем
`--no-sync`, чтобы не удалять его посторонние пакеты. Эта команда обновляет
`pyproject.toml` и `uv.lock`, но сама пакеты не устанавливает.

Добавление зависимости с установкой в используемое общее окружение:

```bash
UV_PROJECT_ENVIRONMENT=/home/user/vscode/python/venv/.venv uv add имя-пакета
```

Скопировать `.env.example` в `.env` и заполнить `OPENAI_API_KEY` локально.
Не публиковать `.env` и не отправлять ключ в переписку. Переменная окружения
имеет приоритет над `.env`. В `OPENAI_MODEL` можно указать модель с поддержкой
Responses API, streaming и `reasoning.effort=medium`; по умолчанию `gpt-5-mini`
для первых проверок. Для сложных задач модель можно заменить через конфигурацию.
Запросы выполняются только после нажатия «Решить»/«Решить заново» и расходуют
API-кредиты. Наличие ключа само по себе не подтверждает доступ к API.

Запуск:

```bash
/home/user/vscode/python/venv/.venv/bin/python -m streamlit run app.py
```

Открыть http://127.0.0.1:8501. Ввести, например, «Найти производную x²» и нажать
«Решить». Дождаться ответа, исправить условие и нажать «Решить заново».
Новое решение заменяет предыдущее. Ответ модели необходимо проверять.

Запрос идёт в отдельном asyncio event loop; UI опрашивает безопасный снимок
состояния каждые 0,5 секунды. Ресурс обработчика привязан к сессии Streamlit
через `cache_resource(scope="session", on_release=...)`: перезапуски интерфейса
используют тот же обработчик, отключение сессии освобождает его ресурсы.
Редактирование условия отменяет текущий запрос. Счётчик поколений не позволяет
позднему ответу отменённого запроса заменить актуальный ответ. Отмена закрывает
локальный поток и не гарантирует отмену уже выполненной сервером работы и её стоимости.
Частичный ответ при ошибке остаётся виден со статусом ошибки.

Состояние хранится только в памяти сессии; перезагрузка вкладки может создать
новую сессию. Аудио и файлы истории не создаются. В Responses API передаётся
только условие и инструкция, с `store=False`; это отключает хранение Response
для последующего извлечения, но не является гарантией отсутствия всех серверных
логов провайдера.

Проверки без ключа, реальных API-запросов и аудиоустройств:

```bash
/home/user/vscode/python/venv/.venv/bin/python -m unittest discover -s tests -v
```

Использованы [OpenAI Python SDK](https://developers.openai.com/api/reference/python)
и [Responses streaming](https://developers.openai.com/api/docs/guides/streaming-responses).

### Проверка локального распознавания

Без API-кредитов: распознавание короткого готового аудиофайла на русском.
В веб-интерфейсе загрузить запись (до 20 МБ) в разделе «Распознавание аудиофайла»
и нажать «Распознать». Текст и время обработки появятся в этом разделе.
Кнопка «Использовать как условие» явно заменяет текст в редакторе, после чего
его можно исправить и решить. Без нажатия этой кнопки ручные правки сохраняются.
Распознавание само не запускает платные API-запросы.

Файл передаётся декодеру в памяти через `BytesIO`, временные файлы не создаются.
ASR выполняется в потоке через `asyncio.to_thread` на существующем обработчике
сессии; интерфейс и запрос решения продолжают работать. Дополнительные файлы
во время распознавания не ставятся в очередь. Модель общая для процесса,
лениво загружается один раз, её инференс сериализован блокировкой.
Отключение сессии отменяет ожидание ASR; уже начатое CPU-вычисление завершается
в своём потоке, после чего освобождаются ресурсы. Время в UI включает ожидание
модели, её первую загрузку, декодирование, VAD и распознавание.

Веб-интерфейс использует только локальный кеш модели. Если он ещё не заполнен,
выполнить команду ниже один раз с доступом к интернету. CLI также доступен отдельно:

```bash
/home/user/vscode/python/venv/.venv/bin/python transcribe.py /путь/к/задаче.wav
```

Для первой проверки достаточно 10–30 секунд чёткой речи, например:
«Найдите производную функции икс в квадрате плюс три икс».
Можно использовать WAV, MP3, M4A и другие форматы, поддерживаемые PyAV.
Скрипт выводит текст и временные метки в терминал, не сохраняет аудио или
транскрипцию и не отправляет их в облако.

При первом запуске скачиваются веса `base` в кеш Hugging Face
(обычно `~/.cache/huggingface`); это файлы модели, а не история разговора.
После скачивания можно запретить доступ к сети:

```bash
/home/user/vscode/python/venv/.venv/bin/python transcribe.py /путь/к/задаче.wav --offline
```

Распознавание использует CPU INT8, четыре вычислительных потока, одного
работника и встроенный в faster-whisper Silero VAD. Один экземпляр
`SpeechRecognizer` переиспользует одну модель и последовательно обрабатывает
файлы. При будущей интеграции этот синхронный метод нужно вызывать вне
asyncio event loop через `asyncio.to_thread`.

Автоматические тесты подменяют ASR-модель и ничего не скачивают. Они проверяют
обвязку, но не качество русского распознавания: его нужно проверить на
аудиофайле отдельно. Запуск CLI загружает модель заново на каждый новый процесс;
в приложении один экземпляр переиспользуется в течение жизни процесса.

Основано на [официальной документации faster-whisper](https://github.com/SYSTRAN/faster-whisper).

PyAV ограничен версией ниже 19: faster-whisper 1.2.1 использует аргумент
`metadata_errors`, удалённый из `av.open` в PyAV 19. Совместимость декодера
проверяется отдельным тестом на синтетическом WAV без скачивания модели.
